# Tafita

Tafita fait découvrir Madagascar à travers ses lieux, ses pépites et sa culture, et permet aux voyageurs de partager leurs avis et leurs propres découvertes.

Le cadrage du produit se trouve dans [docs/CADRAGE.md](docs/CADRAGE.md).

## Structure

- `app/` contient l'application Expo (iOS, Android et web).
- `db/migrations/` contient le schéma de la base de données.
- `docs/` contient la documentation produit.

## Démarrer

```bash
cd app && npm install
```

```bash
cp .env.example .env
```

```bash
npx expo start
```
